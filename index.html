07 · Problem Solving

문제를 해결하는 방식

09
STEP 01

흐름부터 확인

문제가 발생하면 시스템 전체 구조와 데이터가 이동하는 경로부터 확인합니다.

STEP 02

원인 범위 축소

파일, 권한, 경로, 서비스 설정, 네트워크 연결 등을 단계적으로 확인합니다.

STEP 03

다시 검증

설정을 변경한 뒤에는 동일한 조건에서 다시 테스트하여 실제로 문제가 해결됐는지 확인합니다.

EXPERIENCE

로그가 수집되지 않을 때

단순히 설정을 다시 적용하기보다 로그 파일 생성 여부, 파일 권한, 실제 저장 경로, Agent 설정과 서버 연결 상태를 순서대로 확인하며 원인을 좁혀갔습니다. 이런 방식은 DB 권한 문제나 서비스 연동 문제를 해결할 때도 동일하게 적용했습니다.
